音视频下载器使用教程

基于 yt-dlp 与 FFmpeg 的 Windows 图形化下载工具

快速开始

  1. 在“设置”页确认 yt-dlp.exe、ffmpeg.exe、ffprobe.exe 的路径正确。可点击“测试工具路径”。
  2. 切换到“视频下载”或“无损音乐”，粘贴网页地址。
  3. 选择输出目录和格式，点击“开始下载”。
  4. 下载时可使用“暂停”“继续”“停止”控制任务；“暂停”会挂起当前 yt-dlp 进程。
  5. 底部日志会显示进度和错误信息，下载完成后可用 ffprobe 校验音视频流。

无损音乐说明

重要：从 YouTube 等有损来源转换出的 FLAC、ALAC 或 WAV 只是文件格式转换，不能恢复原始音质中被压缩掉的信息。只有 Tidal、Qobuz、Bandcamp 等提供无损流的来源，配合登录 Cookies，才可能获得接近或真正无损的音频。

音乐标签使用 -x 提取音频，再交给 FFmpeg 转为所选格式，并可选写入封面和元数据。格式选择：FLAC、ALAC、WAV。

合集下载

YouTube 播放列表

  1. 打开 YouTube 播放列表页面，复制浏览器地址栏中的播放列表 URL。
  2. 在“无损音乐”标签粘贴地址，勾选“合集模式”。
  3. 合集范围留空表示下载全部；也可以填写 1-50 或 1,3,5 只下载指定条目。
  4. 点击“开始下载”，文件会保存到所选目录下的“合集标题”子文件夹中。

B 站分P合集

  1. 打开包含多个分P的 B 站视频页面，复制 BV 地址。
  2. 在“无损音乐”标签粘贴地址，勾选“合集模式”。
  3. 每个分P会保存为单独的 FLAC/ALAC/WAV 文件，并按合集名创建子文件夹。
  4. 已下载过的条目会自动跳过；合集中断后再次运行会从剩余条目继续。

支持网站概览

yt-dlp 支持数千个网站，常见包括：

  • 视频：YouTube、Bilibili、Vimeo、Dailymotion、Twitch、Niconico、Pornhub
  • 短视频：TikTok、抖音、快手、Instagram Reels、Facebook Watch
  • 社交：X / Twitter、Instagram、Facebook、Reddit、Tumblr
  • 音频：SoundCloud、Bandcamp、Mixcloud、网易云音乐（部分）
  • 直播回放与更多站点以官方列表为准

完整支持列表：yt-dlp supportedsites.md

官方下载仓库

  • yt-dlp 主仓库：https://github.com/yt-dlp/yt-dlp
  • yt-dlp 发布下载：https://github.com/yt-dlp/yt-dlp/releases
  • FFmpeg 官方下载：https://ffmpeg.org/download.html
  • Windows FFmpeg 预编译包：https://github.com/BtbN/FFmpeg-Builds/releases
  • FFprobe 通常随 FFmpeg 一起提供，无需单独下载。

升级工具后如何恢复

  1. 下载并解压新版 yt-dlp 或 FFmpeg。
  2. 打开程序“设置”页，手动重新选择 yt-dlp.exe、ffmpeg.exe、ffprobe.exe。
  3. 或者点击“自动查找工具”，程序会扫描程序目录及其上级目录中的匹配文件。
  4. 点击“保存设置”。配置保存在程序同目录的 VideoDownloader.config，可随文件夹整体复制。

常见问题

下载的视频没有声音

确认 ffmpeg 路径正确，并使用“最佳 MP4”或“最佳质量”。这些格式会自动合并最佳视频流和音频流。若仍无声，请升级 ffmpeg 和 yt-dlp。

YouTube 或某些网站下载失败

通常与登录、年龄限制、地区限制或反爬有关。可在设置页填写导出的 Cookies 文件、配置 HTTP 代理，例如 http://127.0.0.1:7890，并把“浏览器伪装”保持为“自动”。如果提示“Sign in to confirm you’re not a bot”，可把“Cookies 来源”改为 Chrome 或 Edge 直接读取浏览器登录状态；如果浏览器 Cookies 解密失败，则重新导出 cookies.txt 后改回“Cookies 文件”。

提示找不到 ffprobe

FFprobe 是 FFmpeg 的一部分，从 Windows FFmpeg 压缩包中的 bin 文件夹选择 ffprobe.exe。

无损音乐音质不达预期

确认来源本身提供无损流，而不是仅把有损 MP3/AAC 转码成 FLAC。输出文件大小不能作为无损判断依据。
