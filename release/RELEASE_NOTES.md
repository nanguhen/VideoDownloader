# VideoDownloader v1.0.0

首个开源版本。

## 功能

- 视频下载：最佳 MP4、最佳质量、MP3。
- 无损音乐：FLAC、ALAC、WAV。
- YouTube 播放列表和 B 站分P合集下载。
- 合集范围、下载存档和断点续传。
- 暂停、继续、停止和进程树控制。
- 数字进度、合集条目进度和完整日志。
- Cookies 文件及 Chrome、Edge、Firefox Cookies 来源。
- 浏览器伪装、代理、工具路径自动检测和三套界面皮肤。

## 便携包

`VideoDownloader-v1.0.0-portable.zip` 包含：

- `VideoDownloader.exe`
- `使用教程.html`
- `README.txt`
- `LICENSE.txt`
- `THIRD_PARTY_NOTICES.txt`

便携包不包含 `yt-dlp.exe`、`ffmpeg.exe` 或 `ffprobe.exe`。请从第三方官方
项目下载，并在程序的“设置”页选择对应路径。
