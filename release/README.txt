VideoDownloader v1.0.0
=====================

运行要求：
- Windows 10/11
- .NET Framework 4.8
- yt-dlp.exe
- ffmpeg.exe
- ffprobe.exe

使用方法：
1. 将 yt-dlp.exe、ffmpeg.exe、ffprobe.exe 放在任意目录。
2. 启动 VideoDownloader.exe。
3. 打开“设置”，选择三个工具路径并保存。
4. 视频下载和音乐下载分别在不同的标签页操作。

合集下载：
- YouTube 播放列表：粘贴播放列表地址，勾选“合集模式”。
- B 站分P：粘贴 BV 地址，勾选“合集模式”。
- 合集范围留空表示全部，也可填写 1-50 或 1,3,5。

本程序不包含 yt-dlp、FFmpeg 和 ffprobe。第三方工具和许可证说明见
